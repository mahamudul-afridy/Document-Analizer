# Project: AI-Powered Document Intelligence System

## 1. Project Overview

Build a complete, production-quality AI-Powered Document Intelligence System for processing, extracting, validating, managing, and searching business documents.

The application should automate the processing of thousands of business documents, including:
- Digital and scanned PDF files.
- JPG, JPEG, PNG, and TIFF images.
- Excel files (XLSX and XLS).
- CSV files.

The system must extract financial and invoice information, perform cross-document verification, detect inconsistencies, and provide searchable structured information through a modern web dashboard and REST API.

**IMPORTANT: Website Design and Branding Reference**

Use the following website as the primary visual reference for the entire application's design, branding, colors, typography, spacing, component styling, and overall user experience:

https://cottagehomecare.com/

Do not copy its business content, logo, or healthcare-related elements. Adapt its visual identity to a professional AI-powered enterprise document intelligence platform.

## 8. AI Information Extraction

Extract the following information from invoices:

- Invoice Number.
- Invoice Date.
- Supplier Name.
- Customer Name.
- Subtotal.
- Tax.
- Total Amount.
- Currency.
- Line Items.

For each line item, extract:
- Description.
- Quantity.
- Unit Price.
- Tax.
- Line Total.

Return structured JSON.

Important rules:
- Never invent missing information.
- Return null for unavailable fields.
- Track confidence scores where supported.
- Preserve source document references.
- Flag uncertain extraction results.
- Allow manual correction.

Example JSON:

{
  "invoice_number": "INV-2026-001",
  "invoice_date": "2026-10-15",
  "supplier_name": "ABC Corporation",
  "customer_name": "XYZ Limited",
  "subtotal": 1000.00,
  "tax": 150.00,
  "total": 1150.00,
  "currency": "USD",
  "line_items": [],
  "confidence": {},
  "validation_status": "passed"
}
